# Emulator cores for Spel

The RetroArch (libretro) cores from EmulatorJS 4.2.3's npm packages (`@emulatorjs/core-fceumm`, `-snes9x`, `-gambatte`,
`-mgba`, `-smsplus`, `-genesis_plus_gx`), unchanged: the same files, repacked from 7z (LZMA) into zip, because the TV
couldn't unpack the 7z archives of the bigger cores (SNES stopped at "Decompress Game Core 0%").

Each archive keeps the core's `license.txt` (GPL for most; snes9x has its own non-commercial license). Source code:
https://github.com/EmulatorJS/EmulatorJS and https://github.com/libretro.
